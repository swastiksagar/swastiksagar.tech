# Swastik Sagar — Portfolio

React + Vite portfolio site.

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173
```

## Build and deploy
```bash
npm run build      # outputs to dist/
```
Deploy the `dist/` folder to Netlify, Vercel or GitHub Pages
(Netlify/Vercel: build command `npm run build`, output directory `dist`).

## Edit your content
- `src/data.js`: projects, experiments, certifications, tools and links
- `src/App.jsx`: layout and sections
- `src/styles.css`: all styling
- `public/photo.jpg`: your photo
